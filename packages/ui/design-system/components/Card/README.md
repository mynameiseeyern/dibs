# Card

The shell for grouped content: `bg-white-0`, `stroke-soft-200` border, `radius-lg`, `shadow-sm`, `space-4` padding (`space-5` from 768px). Variants: `db-card--sticker` (ink border and `shadow-pop`, for the one card that matters now), `db-card--violet` and `db-card--ink` (white text).

- The consumer provides the content. Don't nest cards. Intentional addition: the templates' widgets all sit on this shell.
