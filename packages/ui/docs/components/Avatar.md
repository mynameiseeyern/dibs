# Avatar

Round member avatars: a photo, or initials on one of five friendly fills (violet, lime, sun, mint, tangerine), picked from the member id so a person keeps their colour. The AI member always uses `dibs-ai-member.svg`.

- The consumer provides the image with `alt`, or one or two initials. Stacks (`db-avatar-group`) show up to three faces and a `+N`, with an `aria-label` giving the count.
