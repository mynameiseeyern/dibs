# SegmentedControl

Two to four mutually exclusive options in a `bg-soft-200` track; the chosen one inverts to `bg-strong-950` with `text-white-0`, so the selected state is 15:1 against the track (a white pill on `bg-soft-200` was only 1.2:1). Used for the group vibe (Chill, Extra, Straight up) and split mode.

- The consumer provides the buttons with `aria-pressed` and a group `aria-label`. Labels stay one or two words so it fits at 343px.
