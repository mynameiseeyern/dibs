# ProgressBar

A 10px pill track (`bg-soft-200`) with a violet fill, lime (`db-progress--accent`) for money paid back, with a 1.5px `stroke-strong-950` edge because lime alone is 1.1:1 on the track in Light; `success-dark` for done.

- The consumer provides the value with `role="progressbar"`, `aria-valuenow` and a label, and a text line saying the numbers (“4 of 6 voted”).
